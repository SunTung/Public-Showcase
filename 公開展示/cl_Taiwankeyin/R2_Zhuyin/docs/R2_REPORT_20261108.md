## 功能驗證範圍
1. 大千37注音根鍵與五聲調映射；輸入大小寫標準化、非法鍵拒絕、首個聲調不可獨立啟動組字。
2. 聲母→介音→韻母順序與有限的單獨聲母有效性檢查；不是所有國語音節的完整合法性判斷。
3. 逐鍵預組字、完成聲調、連續多音節、候選列表、上一個/下一個選擇、越界選項拒絕。
4. 退格移除末尾字根、退格重開聲調、退格還原上一個候選、取消輸入不學習。
5. 單字/多字 TSV 繁體候選、同音異字 baseline 排序與個人經驗排序。
6. 只有 `select()` 才會呼叫 R1 `Engine.commit`；預組字時沒有詞庫寫入、無跨標點錯誤學習。
7. 完成候選選擇後保留 R1 原本的括號、冒號軟連接與標點硬斷句。
8. 同音重複選「再」後，可超過預設「在」的詞典排序；持久化重啟一致，清空後恢復 baseline。
9. 敏感欄位 `set_sensitive(true)` 允許文字輸入，但阻止 R1 學習落庫。

## 本輪實際修復

## 嚴格限制
- **沒有**可安裝 Windows 輸入法、Windows GUI/EXE、TSF DLL；本環境只完成 Linux 主機下 headless CLI 與原生函式庫。
- **沒有**完整臺灣繁體日常詞典。示範詞庫為自行編寫、僅用於測試；大量生僻字、異讀、長詞缺漏。R2-B 應接入獨立可稽核的繁體注音字典。
- **沒有**完整國語聲韻組合合法性語法；目前使用順序限制與詞庫命中控制輸出，尚需精確處理特殊音節及模糊音。
- **沒有** Windows x64 本機編譯、候選 UI、MSVC/Win11/Word/Chrome 系統驗收。
- 候選分數係初始工程權重，尚未做規模化準確度、延遲或詞頻比較；目前測試證明功能連接，不證明泛化效果。
