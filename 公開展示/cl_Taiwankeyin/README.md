# cl_Taiwankeyin｜繁體細胞注音輸入法（Windows）

狀態：**R0 規格基線**（非可安裝完成版）。預計程式名 \`cl_Taiwankeyin.exe\`；Windows 全系統輸入法需配套 TSF DLL。

- [完整規劃、核心規格、測試向量](PLAN.md)
- 本專案的 GitHub 區域為**公開備份**，不保存使用者詞庫與未授權的私人 CELL 工程材料。
- 主要功能：最多10個有效字的短句經驗、遇一般標點斷句、遇 \`（）〔〕〈〉｛｝：\` 保留前後上下文、候選詞經驗排序。
- 原生核心採 C++17；正式 Windows 介面採 TSF；實際通過門檻以 PLAN.md 各階段驗收為準。
