# CELL 中英繁簡概念字典｜獨立工程 v0.1

這是**新建、獨立資料模型與第一批人工整理的 90 個概念種子**，並不是把既有 Chewing 158,905 筆詞庫刪去標籤後重新命名。舊輸入法字典繼續保持正常運行，待新字典擴充到可驗收的覆蓋率之後，再以可回退的切換方式取代。

## 定位

- 一個 `concept_id` 表示**一個語義概念**，連結繁體（zh-Hant-TW）、簡體（zh-Hans-CN）和英文（en）表述；讀音另外存為注音和 Hanyu Pinyin。
- 相同英文可能有多個中文形式，同一簡體字也可能對應多個繁體字；不用單向逐字替換冒充精確翻譯。
- `發／髮→发`、`後／后→后`、`乾／幹→干` 在獨立表保存歧義與語義線索。
- 「硬碟／硬盘」、「記憶體／内存」屬不同地區的用詞對應，而非單純字形變換。
- 原始資料只保留 CELL 自編 seed（`data/cell_seed.tsv`），沒有匯入 Chewing CSV、OpenCC 轉換表或現成英文詞條翻譯清單；後續比對他人資料僅用於發現缺口與驗證，不把來源內容直接編入本庫。

## 使用

```bash
python src/build_dictionary.py --input data/cell_seed.tsv --output build/cell_concepts.sqlite3
python -m unittest discover -s tests -v
```

資料庫 `expression(locale,value)` 可直接查詢三語表述，並取得共享概念 ID；`pronunciation(scheme,value)` 提供兩種讀音索引。資料庫 schema 已設計供 Android/Windows/CELL 代理人/研究模組共同使用，不含平台依賴。

## 現況與下一關

**這是 90 個概念的第一階段測試種子，不是完整詞典。** 英文 gloss 為短譯標籤，並非可直接替代英漢辭典的完整義項定義；詞條與讀音仍需逐條交叉校對。尤其多義詞需加詞性、語域、義項、方言、例句及來源驗證紀錄。下一步分別擴充 Unicode 字形層、繁簡詞彙層、三語語義層；不由 Unicode 字形對應直接推導英文語義。

> 「自有資料模型及自編詞條」不代表字符、通用詞彙或標準資料的歷史來源被抹除。資料庫本身不含他人產品名稱、內部鍵值或原始詞表；研究引用與查核依據保存在工程外部說明，而非偽裝為原創事實。
