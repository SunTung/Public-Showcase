## 功能與實際核對
1. ICU 字素分段，測試中英文字、組合附加符與 ZWJ emoji。
2. 最多10個有效字的滑動上下文；軟連接括號與冒號保留但不佔字額度。
3. 硬斷句符號清空上下文並阻斷跨句短語；支援全形及半形選定的六種硬斷句符號與換行。
4. 每次已確認輸入，自動記錄最多10有效字的滾動後綴短句；不保存超過10有效字的組合。
5. 選字統計、前文關聯、負向糾錯，分數排序可重播。
6. SQLite WAL、transaction commit/rollback、持久化與清除學習庫。
7. 開關學習與敏感欄位（由未來 TSF Adapter 指示）控制記憶寫入。
8. 僅字素完整且有效的 UTF-8 受理，非法字串拒絕。
